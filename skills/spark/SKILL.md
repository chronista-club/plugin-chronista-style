# Spark

記憶操作の前に [creo-memories の接続と未接続時の扱い](../chronista-style/reference/memory-connection.md) を読む。以下の記憶手順は、対応ツールが利用できる場合に実行する。

ひらめきを、意味付けされる前の生の状態で creo-memories に置く。**速さと原文が全て。**

## 実行手順

### 1. 言葉を受け取る

呼び出し時にユーザーが添えた言葉があればそれが火花。無ければ地の文で一行だけ「何が降ってきた？」と聞き、次の発言をそのまま火花とする。

### 2. そのまま pack する

接続済みの creo-memories の `remember` を、実際のツール名・引数スキーマに合わせて一回呼ぶ。未接続なら原文と「未保存」を返して終える。

- `category`: `spark`
- `content`: ユーザーの言葉を**原文のまま**。先頭に `# [SPARK] ` を付け、本文は `> ` で引用する。それ以外は書かない
- `atlasId`: 接続ガイドの Atlas 候補を使い、取得済み情報に exact match する ID があればそれ。候補文字列を ID として渡さない。不明なら省略（Personal に入る）し、報告で一言添える。置き場で止まらない
- `supersedes`: `[]`（重複検出を切る。火花は重なってよい）
- `tags`: `["spark"]` と、プロジェクト名が分かればそれ

### 3. 一行で報告する

成功時は実際に返された memory ID を一行返す。失敗なら未保存、成否不明なら保存結果未確認と報告する。それで終わり。

## やらないこと

- 要約しない、見出しを付け直さない、タグを推測で増やさない、「AI の理解」を書かない。整えると火花が死ぬ
- 成功基準・非対象・Branch slug を聞かない。それは GO のときに todo へ進めるときの話
- 作業に入らない。pack した後は Conception の構え — 話したければ話す、話さなければそこで終わる
- 自分の連想があれば、memory に混ぜず会話で言う（「それ、さっきの X と繋がってる」）
